## Documentation shape

These docs follow the [Diátaxis](https://diataxis.fr/) framework:

- **How-to guides** — task-oriented, step-by-step. "How do I do X?"
- **Reference** — descriptive, factual. "What is X and how does it behave?"

Rendered Quarto reports are published alongside this site under
[`/quarto/`](https://caleyest.github.io/combocizes/quarto/report.html).
